Port

Type: object

A input, output or bidirectional port of a module.

Ports pass signals into, or out of the module, e.g. the clock, data signals, etc.
In comparison, wires stay inside the module.

Ports can have one or more bits, therefore they connect to a list of net names in nets.
The nets are sorted, with the least significant bit first.

Type: array of string

One net name per bit, least significant bit first.

or const:z.

The length of the nets is equal to the width of the port.
